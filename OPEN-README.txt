MVP санҷида шуд:
✓ Каталог (6 маҳсулот), ҷустуҷӯ, категорияҳо
✓ СНЕЖКА: 10 кг = 75 с. · 20 кг = 140 с.
✓ Сабад + ҷамъ + фармоиш ба WhatsApp
✓ Бақайдгирӣ (форма / Google)
✓ Ҳисобкунаки ранг + интихоби ранги девор
✓ 5 забон (tg/ru/en/zh/fa)
✓ Админ маҳаллӣ: admin / 12345
✓ Админ → сайт: бо Google-и админ «Нигоҳ доштан»

Чӣ тавр сурат/нархро худатон иваз мекунед:
1. Админро аз силкаи боло дар Chrome кушоед.
2. «Ворид шудан бо Google-и админ» → аккаунти соҳиби мағоза.
3. Маҳсулотро тағйир диҳед → «Нигоҳ доштан».
4. Сайтро нав кунед — тағйирот дар интернет пайдо мешавад.

Агар Google хатогӣ диҳад (unauthorized-domain):
Firebase Console → Authentication → Settings → Authorized domains
→ sinojon-bot.github.io-ро илова кунед.

1. OPEN-SITE.cmd ё OPEN-ADMIN.cmd
