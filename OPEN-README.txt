ЭКО ПАЙНТ — MVP (нусхаи корӣ)

1. ZIP-ро пурра «Извлечь всё» кунед. Танҳо index.html-ро ҷудо накунед.
2. Барои сайт OPEN-SITE.cmd-ро кушоед.
3. Барои админ OPEN-ADMIN.cmd-ро кушоед.
4. Тирезаи серверро то анҷоми кор набандед.

MVP чӣ кор мекунад:
- Каталог, ҷустуҷӯ, 5 забон
- Сабад (нигоҳ дошта мешавад) ва фармоиш ба WhatsApp
- Ҳисобкунаки ранг ва интихоби ранги девор
- Профил / бақайдгирӣ
- Админ: тағйири маҳсулот ва пардохт (танҳо бо Google-и админ)

Google, маълумоти харидорон ва нигоҳ доштани тағйирот дар сервер интернет мехоҳанд.
Дар админ «Пайваст шудан бо Google»-ро пахш кунед ва Google-и админро интихоб кунед.
Агар дар сервер ҳанӯз номҳои INTERIOR/FACADE бошанд, пас аз пайваст каталог ба MVP нав мешавад.
Танҳо номи admin ва рамзи панели маҳаллӣ ҳуқуқи тағйири сервер намедиҳанд.
Нархҳои пешфарзро дар админ ба нархи воқеии мағозаи худ иваз кунед.
