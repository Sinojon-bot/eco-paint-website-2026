ЭКО ПАЙНТ — MVP (нусхаи корӣ)

СИЛКАҲОИ ИНТЕРНЕТ (Chrome):
Сайт:  https://sinojon-bot.github.io/eco-paint-website-2026/
Админ: https://sinojon-bot.github.io/eco-paint-website-2026/admin/

Чӣ тавр сурат/нархро худатон иваз мекунед:
1. Админро аз силкаи боло дар Chrome кушоед.
2. «Ворид шудан бо Google-и админ» → аккаунти соҳиби мағоза.
3. Маҳсулотро тағйир диҳед (сурат, нарх) → «Нигоҳ доштан».
4. Сайтро нав кунед — тағйирот дар интернет пайдо мешавад.

Агар Google хатогӣ диҳад (unauthorized-domain):
Firebase Console → Authentication → Settings → Authorized domains
→ sinojon-bot.github.io-ро илова кунед.

Дар компютер:
1. Барои сайт OPEN-SITE.cmd-ро кушоед.
2. Барои админ OPEN-ADMIN.cmd-ро кушоед.
3. Тирезаи серверро то анҷоми кор набандед.
Маҳаллӣ: admin / 12345 — танҳо ҳамин компютер (ба интернет намеравид).

MVP чӣ кор мекунад:
- Каталог, ҷустуҷӯ, 5 забон
- Сабад ва фармоиш ба WhatsApp
- Ҳисобкунаки ранг ва интихоби ранги девор
- Профил / бақайдгирӣ
- Админ: тағйири маҳсулот ва пардохт (барои интернет — бо Google)
