ЯК БОР — баъд ҳама чиз АВТОМАТ мешавад

Вақте админро тағйир медиҳӣ, худаш ба телефон меравад.
Танҳо ЯК МАРОТИБА инро кун:

1) Кушо: https://console.firebase.google.com/
2) Лоиҳа: eco-paint
3) Build → Firestore Database → Rules
4) ҲАМА матни кӯҳнаро пок кун, инро гузор:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

5) Тугмаи Publish / Опубликовать

БАЪД:
Админ → тағйир → Нигоҳ доштан
→ худаш ба интернет меравад
→ телефонро нав кун — ҳамонро мебинӣ

Дигар чизе лозим нест.
