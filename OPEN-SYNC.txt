Eco Paint — то тағйироти админ ба телефон равад (1 маротиба)

Вазифа: ҳангоми «Нигоҳ доштан» дар админ, маҳсулот ба интернет меравад
ва дар телефон ҳам пайдо мешавад. Маълумот нест намешавад.

==================================================
КАДАМ 1 (муҳим): Қоидаҳои Firebase
==================================================
1. Кушо: https://console.firebase.google.com/
2. Лоиҳаи eco-paint-ро интихоб кун
3. Аз меню: Build → Firestore Database → Rules
4. ҲАМА матни кӯҳнаро нест кун ва матни файли firestore.rules-ро гузор
   (дар папкаи лоиҳа: firestore.rules)
5. Publish / Опубликовать

==================================================
КАДАМ 2 (тавсия): Домени Google
==================================================
Authentication → Settings → Authorized domains → Add domain
→ sinojon-bot.github.io

==================================================
КАДАМ 3: Админ
==================================================
1. https://sinojon-bot.github.io/eco-paint-website-2026/admin/
2. Ворид бо admin / 12345
3. Маҳсулотро тағйир деҳ → Нигоҳ доштан
4. Бояд нависад: «Ба интернет рафт»

==================================================
КАДАМ 4: Телефон
==================================================
https://sinojon-bot.github.io/eco-paint-website-2026/
Саҳифаро нав кун.
